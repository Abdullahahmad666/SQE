# Software Quality Engineering — Test Automation

Coursework for Software Quality Engineering covering three kinds of testing:

- **BDD / acceptance testing**: Gherkin scenarios (`myfeature.feature`) that drive a Chrome browser to create a collection in Metabase, plus Python step definitions for OrangeHRM tests (`orangehrmsteps.py`)
- **Unit testing**: in `Unit Testing/`
- **API testing**: in `APITesting.rar`

## Tech
Python · BDD (Gherkin) · browser automation · unit testing · API testing
